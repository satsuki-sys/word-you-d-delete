An entry for the make.fun competition [The Word You'd Delete From the Dictionary](https://make.fun/c/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2).

## The entry

`word`

A dictionary is a book of words, so erasing the word "word" leaves it unable to name what it contains.

## How it works

`main.py` writes the single word to `/output/entry.txt` — exactly one word, no trailing newline, no extra text. Run it with:

```sh
python3 main.py
```
